# USA IN YOUR LANGUAGE

Prototipo del directorio de servicios por idioma y cercanía.

## Abrir
Servir la carpeta mediante HTTP para revisar el diseño. La geolocalización requiere HTTPS o localhost. No necesita instalación ni compilación.

## Incluido
Diseño móvil aprobado; promociones con imágenes de ejemplo; familias y especialidades; selección independiente de idioma de interfaz y atención; filtros; perfiles de ejemplo y favoritos locales.

## Pendiente
Autenticación, registros y aprobaciones reales, base de datos, ubicaciones de negocios, traducción completa y membresías. Elegir un idioma aún no traduce toda la interfaz. Los negocios, promociones y distancias son ficticios. Las fotos de demostración fueron generadas con IA.

Los archivos register.html, app.js y styles.css se conservan como prototipo anterior.

## Cuentas y solicitudes en prueba privada

Se añadió un servidor local con cuentas, verificación por bandeja de prueba, sesiones, solicitudes y aprobación/rechazo administrativo. Ejecutar con Python; ver [backend/README.md](backend/README.md). Un hosting estático no ejecuta este servidor. La configuración de producción y el envío real de correo siguen pendientes.
